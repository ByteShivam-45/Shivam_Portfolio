# Shivam's Portfolio

A modern, responsive personal portfolio website showcasing my work as a Computer Science student and Python/AI developer.

## 🌐 Live Portfolio

[![Live Portfolio](https://img.shields.io/badge/🚀_Live_Portfolio-Visit_Website-7c8795?style=for-the-badge)](https://shivam-portfolio-plum-five.vercel.app/)

## 📋 Overview

This is a clean, minimalist portfolio website built with HTML and CSS featuring:
- Modern dark theme design
- Responsive navigation bar with smooth scrolling
- Hero section with professional introduction
- Links to LinkedIn, GitHub, and contact email
- Professional styling with the Inter font family

## 🎨 Features

- **Fixed Navigation Bar** - Sticky header with navigation links to different sections
- **Hero Section** - Eye-catching introduction with profile image and call-to-action buttons
- **Dark Theme** - Modern dark color scheme (#111111 background) with glassmorphism effects
- **Responsive Design** - Mobile-friendly layout using viewport meta tags
- **Smooth Scrolling** - Enhanced user experience with CSS scroll-behavior
- **Professional Typography** - Google Font "Inter" for clean, modern aesthetics

## 📝 Customization

To customize this portfolio:

1. **Update Content** - Edit `index.html` to add your own text, sections, and information
2. **Modify Styles** - Adjust colors, fonts, and layout in `style.css`
3. **Replace Images** - Replace `profile.jpg` and `background.jpg` in the `assets/` folder
4. **Add Sections** - Extend the HTML with additional portfolio sections as needed

## 💡 Tips

- The navbar uses smooth scrolling with anchor links (`#section-id`)
- All colors and spacing can be easily modified in `style.css`
- The design uses CSS flexbox for responsive layouts
- Glassmorphism effects are created with `backdrop-filter: blur()`
